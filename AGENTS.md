# AI Collaboration Disclosure

This project was developed in collaboration with AI coding assistants (specifically Google Antigravity).

Key details regarding the authorship and development of this codebase:

*   **Original Code and Concept**: This project is entirely based on an original bash script written and developed by the project owner to manage and compress video libraries.
*   **AI Assistance**: AI agents were used as a pair-programming partner to help port the original logic into a native C++ and Qt6 desktop application, refactor database calls, and construct build and packaging configurations.
*   **Human Direction**: The project owner directed and supervised every step of the development process. All architectural directions, encoding settings, bug investigations, design choices, and functional changes were dictated, tested, and approved by the owner.

This disclosure is provided in the interest of transparency regarding the collaborative workflows used to build and maintain this software.
